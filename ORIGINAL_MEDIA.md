## Responsive derivatives

Every original above has locally generated `640w` and `1280w` WebP derivatives in `public/assets/responsive/`. Page-hero photographs also have a `1920w` derivative. The React image component serves the appropriate file through `srcset`; the untouched source files remain in `public/assets/original/` for archival traceability.
